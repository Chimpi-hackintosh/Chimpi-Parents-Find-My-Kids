# Privacidade

Este MVP não coleta, transmite ou sincroniza dados com servidores

Mensagens CHIMPI-SOS são processadas somente no aparelho quando compartilhadas ou coladas pelo responsável

A instalação deve ser consentida. Não envie dados de localização de crianças a terceiros não autorizados

Antes de produção, exigir pareamento autenticado e consentido, segurança, revogação de acesso e testes reais de entrega de mensagens
